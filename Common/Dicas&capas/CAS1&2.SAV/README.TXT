1- Start FMSXDOS ver 1.06 by using the patch file, you can change the .dsk file 
   by .rom file, it is the same.
2- From the title screen press F3 to load the saved game file XXXX.cas .
3- Press  CTRL + F9 
4- Press the letter (t) then space and enter the xxx.cas file .
5- Press the letter (b) to return back to the game.
6- Press F6 to rewind tape.(It is better to do that).
7- From the game press (y) to load the saved game.
8- You can load any stage you need by changing the xxx.cas file in step 4.
9- All msx??.cas for castle 1 and cas??.cas for castle 2.
10-If you need to save your game press F4, but it is better to change the saved
   .cas name to another name by using step #4 above. 
11-Don't save before ending the room, why? Try yourself.
12-It is better to save your game on separately files, because winding the
tape moves very quickly, I mean F7.

I think it is clearly now, and easy to save and load the game, but remember,
the idea not to cheat the game and own all the keys, but to think how to open
the closed door, I cheated the saved game to get more lives only, but sometimes
I cheated to get some keys I lost.
Something else, don't try to get the flowers, its trap.
Enjoy the cleverest game; try to finish castle 1, then castle 2.
