                             -=[ What is needed ]=-

To run SD Snatcher you need fMSX-DOS and all the additional ROM files that are
needed to emulate MSX 2. (the ROM files are usually distributed seperately)

To run the emulator at a good speed a Pentium PC is recommended. For slower PCs,
speed can be gained by turning off sound.

Make sure you read the documentation about fMSX-DOS.


                               -=[ How to run ]=-

To run SD Snatcher, make sure you have all the programs you need, all in the
same directory. Then start the game with this DOS command:

fMSX-DOS -diska sd-s.dsk -adjust 3

You might need additional switches to change sound settings, etc. For more
information about that, look in the fMSX-DOS documentation.

The game will boot up and it will ask you for an 'SCC slot (0=none)'. Now press
'$' (shift-4) and you should get a message saying 'you hit the jackpot! infinite
cash!'. Once you get that, press '1'.

The game will start


                              -=[ What's next ]=-


You can either wait a while and the intro demo will start, or you can press
space and select 'start' to start a new game. Enter 'GILIAN' for the name (that
is what his real name is supposed to be anyway). You will see another introdemo.

After the demo is over, you can play the game for a while. Play through the
start until you encounter your first monster (metal creature). Then load the
saved game from the data-disk and continue playing from there.


                              -=[ The controls ]=-

Cursor keys move Gilian around.
Space is fire button A (select)
ALT is fire button B (cancel)

Use ALT key to speed up the text.

F1 to pause the game
F2 to save the game
F3 to load a saved game (or select 'continue' when the game starts)

The game will ask for different disks (disk 1,2,3 and user disk) when it does
this, hold down the *right* CTRL key and press 1,2,3 for disk 1,2,3 respectively
and press 4 for the user disk.
